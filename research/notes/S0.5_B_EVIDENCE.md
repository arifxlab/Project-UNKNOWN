## 1. Objective

Implement the first deterministic synthetic world capable of producing controlled public environment dynamics while remaining separated from hidden benchmark truth and evaluation state.

S0.5-B establishes the internal world-dynamics layer required before implementing the public observation projection.

---

## 2. Implemented Components

### Deterministic world

Implemented:

* deterministic seeded initialization
* configurable world dimensions
* configurable entity count
* configurable episode horizon
* deterministic entity identifiers
* deterministic entity categories
* deterministic initial positions
* deterministic initial velocities
* positive entity mass
* deterministic static relations
* world timestep
* terminal-state handling
* reset behavior
* deterministic action transitions

### Actions

Implemented:

* `NO_OP`
* `MOVE`
* `INTERACT`

Action configuration is enforced against `PublicEnvironmentConfig.allowed_action_kinds`.

Invalid configured actions are rejected before structural action validation.

### Movement

`MOVE` modifies the selected entity's velocity and then advances the world according to the deterministic transition rule.

The current transition is:

$$
v' = v + \Delta v
$$

$$
p' = p + v'\Delta t
$$

Positions are clamped to the configured world bounds.

### Relations

The minimal world creates deterministic static relations between adjacent entities.

Dynamic relational physics is intentionally deferred to later benchmark stages.

---

## 3. Scientific Boundary

The deterministic world contains only simulation state.

It does **not** contain:

* hidden benchmark condition labels
* ground-truth representation labels
* evaluation scores
* oracle discovery outcomes
* transfer labels
* falsification outcomes
* hidden causal annotations
* benchmark condition metadata

The world therefore remains an implementation layer rather than an oracle for the discovery system.

---

## 4. Configuration Boundary

The public configuration controls which action kinds are available.

The dynamics layer enforces this configuration independently of structural validation.

For example:

* if only `NO_OP` is configured, `MOVE` is rejected;
* if `MOVE` is configured, a structurally valid `MOVE` remains executable;
* `INTERACT` is similarly rejected when not configured.

This prevents the implementation from silently exposing capabilities that the public experiment configuration has disabled.

---

## 5. Determinism Evidence

Deterministic replay is tested using identical seeds and equivalent action sequences.

The test suite verifies:

* identical seeds produce equivalent initial worlds;
* different seeds produce different initial states;
* deterministic identifiers remain stable;
* deterministic relations remain stable;
* equivalent action sequences produce equivalent world trajectories.

The environment therefore has a reproducible dynamics foundation for later experiments.

---

## 6. Validation and Error Handling

The implementation validates:

* initialization before use;
* positive world dimensions;
* positive episode horizon;
* non-negative entity count;
* positive observation history limit;
* allowed action configuration;
* required action parameters;
* valid entity identifiers;
* terminal-state restrictions.

Dedicated runtime errors are used for:

* uninitialized worlds;
* terminal worlds;
* invalid actions;
* general deterministic-world failures.

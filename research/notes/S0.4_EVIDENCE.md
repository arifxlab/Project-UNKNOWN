## 1. Purpose

S0.4 establishes the synthetic environment foundation and the scientific
information boundary required for Project UNKNOWN.

The environment must allow the future discovery system to interact with an
unfamiliar environment through a controlled public interface while keeping
benchmark truth and evaluation information unavailable during discovery.

The central distinction established by this sprint is:

> Representation Failure occurs when required information is available through
> the permitted observation interface but is absent from the current
> representation.

This differs from:

> Information Unavailable, where the required distinction is absent from the
> observation interface and therefore cannot legitimately be recovered by
> representation construction alone.

S0.4 establishes the environment contract. It does not establish successful
autonomous representation discovery.

---

## 2. Scientific Boundary

The environment is divided into three conceptual information layers:

```text
PUBLIC
    Information legitimately available to UNKNOWN.

HIDDEN
    Benchmark-side truth unavailable to UNKNOWN during discovery.

EVALUATION
    Measurements and comparisons performed outside the discovery process.
```

UNKNOWN must not receive through the public interface:

* hidden latent state
* ground-truth representations
* benchmark condition labels
* evaluation labels
* evaluation scores
* oracle outcomes
* future-state information
* benchmark construction information

---

## 3. Environment API

The public runtime establishes:

```text
reset(config, seed)
observe()
step(action)
intervene(intervention)
is_terminal()
episode_metadata()
```

The runtime exposes only public schemas.

The current runtime provides deterministic episode mechanics and contract
validation. Full synthetic world dynamics are intentionally deferred.

## 6. Leakage Protection

The S0.4 leakage audit defines a trust boundary between discovery-time
information and benchmark-side information.

Executable tests currently protect the following boundaries.

### 6.1 Public schema protection

Public schemas are checked for forbidden benchmark concepts including:

* hidden_state
* ground_truth
* ground_truth_representation
* condition
* benchmark_condition
* evaluation
* evaluation_record
* evaluation_label
* evaluation_score
* oracle

### 6.2 Runtime storage protection

The runtime instance is checked to ensure hidden and evaluation state is not
stored in its public runtime attributes.

### 6.3 Import protection

The public runtime is checked to ensure it does not directly import:

```text
unknown.environment.schemas.hidden
unknown.environment.schemas.evaluation
```

### 6.4 Source protection

The public runtime source is checked for references to hidden and evaluation
schema classes.

### 6.5 Type annotation protection

Runtime method annotations are checked to ensure hidden and evaluation schema
types do not enter the public API.

### 6.6 Output protection

Runtime outputs are checked to remain instances of public schema types.

### 6.7 Oracle surface protection

The runtime is checked for the absence of accessors that would expose:

* ground truth
* hidden state
* evaluation records
* oracle results

## 12. Required Counterfactual Conditions

The eventual benchmark must support controlled distinctions between:

```text
Information Unavailable
Representation Failure
Model-Family Failure
Parameter Failure
```

At minimum, paired conditions must allow the evaluator to determine whether
relevant information:

1. is absent from the observation interface;
2. is present but absent from the current representation;
3. is present in the representation but inaccessible to a restricted model
   family;
4. is representable and model-accessible but poorly parameterized.

This is required for later evaluation of representation-level diagnosis.

---

## 13. Reproducibility

The public runtime accepts an explicit seed through:

```text
reset(config, seed)
```

The current runtime shell does not yet use stochastic dynamics. The seed is
therefore part of the reproducibility contract rather than an active source
of current world variation.

Future stochastic environment implementations must preserve reproducibility
without exposing benchmark truth through seed behavior or metadata.

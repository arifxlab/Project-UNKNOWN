# Project UNKNOWN

## Autonomous Concept Formation & Model Discovery

Project UNKNOWN is a research-engineering project investigating whether an artificial system can autonomously detect when its current representation of an unfamiliar environment is inadequate, construct a new reusable concept or representation, and experimentally validate that concept.

The project focuses on:

> Representation discovery before relationship discovery.

UNKNOWN is not intended to be merely a causal discovery system, clustering system, world-model system, feature-learning system, or automated scientific discovery agent.

The central research question is whether a system can recognize that its existing vocabulary for describing an environment is insufficient and then participate in an explicit cycle of concept formation, prediction, intervention, falsification, and transfer.

## Research Question

The primary working research question is:

> Can an artificial system autonomously detect when its current representation of an environment is systematically inadequate, construct a reusable candidate concept that extends that representation, and experimentally determine whether the candidate provides explanatory, predictive, interventional, and transfer value beyond the original representation?

This question is provisional and remains subject to prior-art investigation.
